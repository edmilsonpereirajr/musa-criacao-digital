# Musa Criação Digital

## Visão geral

Loja virtual de produtos digitais.

O sistema será construído com foco em segurança, simplicidade e capacidade de evolução.

## Stack

- Next.js
- TypeScript
- React
- Tailwind CSS
- Supabase
- PostgreSQL
- Supabase Auth
- Supabase Storage
- Mercado Pago
- Vercel
- GitHub
